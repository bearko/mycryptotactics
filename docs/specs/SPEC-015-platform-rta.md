## 1. 概要

bearko.games の共通基盤の RTA（[bearko/mycryptoportfolio の SPEC-001](https://github.com/bearko/mycryptoportfolio/blob/claude/game-portfolio-page-4afqbc/docs/specs/SPEC-001-bearko-games-platform.md) 6 章。本作のレギュレーションは 6.9）に、本作から参加する。「RTA で始める」を選んだときだけ、第 1 章の開始から章クリアまでの時間を共通基盤の SDK で計る。

## 2. 背景と動機

- 共通基盤の段階 4（RTA）。Survivor（全 3 ステージ、Survivor の SPEC-040）・Workshop に続いて本作に対応する
- RTA は「RTA で始める」を選んだときだけ計測する（共通基盤の D10）。ふつうのプレイは計測しない
- レギュレーションは 2 つ（作者の依頼 2026-10-17）：「第 1 章クリアまで」と「全 5 章クリアまで」

## 3. 目標と非目標

### 目標（Goals）

- レギュレーション選択画面の「RTA 第 1 章」「RTA 全 5 章」から始め、結果が bearko.games の RTA ランキングに載る（ログインしていなければ、あとでログインしたときに載る）
- ゲーム内の成績として、ターン数も送る（IGT）

### 非目標（Non-goals）

- Common 以外のレギュレーション・ABSOLUTE での RTA（作者の決定 2026-10-17：Common 固定）
- 第 2 章以降から始める RTA、タイトルをまたぐレギュレーション
- 本作のコードでの Cookie・localStorage の利用（計測の状態は SDK と共通基盤が持つ。再読み込みすると計測は消える）

## 4. スコープ

### 含む

- `prototype/js/platform.js`：RTA の窓口（使えるか・始める・区切り・中断）と、章 → 区切り ID の純関数
- `prototype/js/main.js`：レギュレーション選択画面の RTA の 2 枚、章選択での開始、章クリアでの区切り、敗北・タイトルに戻ったときの中断
- `prototype/data/i18n/`：ボタンと説明の文言（日本語・英語）

### 含まない

- 時間の計り方・経過時間の表示・区間タイムと結果の通知・15 分の無操作（参考記録）・最短時間（共通基盤と SDK が受け持つ）

## 5. 契約と挙動

### 5.1 レギュレーション（共通基盤 `platform/rta.js`）

| ID | 名前 | 区切り（順番どおり） |
|---|---|---|
| `tactics-ch1` | Tactics 第 1 章 | `ch1` 第 1 章クリア（ここで終わる） |
| `tactics-all5` | Tactics 全 5 章 | `ch1` → `ch2` → `ch3` → `ch4` → `clear` 全 5 章クリア |

- ルールは **Common・ヒーロー自由**
- 最短時間（これより速い記録は無効）は共通基盤の 6.9：第 1 章 30 秒・全 5 章 2 分（暫定）

### 5.2 始め方

- レギュレーション選択画面の一覧の下に「RTA」の枠を足し、「RTA 第 1 章」「RTA 全 5 章」の 2 つのボタンと、共通基盤の RTA ランキング（`https://bearko.games/rta/`）へのリンクを置く
- SDK が読めないとき（ローカルで開いたときなど）は、この枠を出さない
- ボタンを押すと、レギュレーションを Common にして（ふつうに Common を選んだときと同じ）RTA のモード（どちらのレギュレーションか）を覚え、ヒーロー選択へ進む
- ふつうのレギュレーションを選んだら、RTA のモードは消える

### 5.3 計測（SDK `BearkoGames.rta`）

| とき | 呼ぶもの |
|---|---|
| RTA のモードで、章選択の **第 1 章** を押して挑戦が始まったとき | `rta.start({ regulation, timerOffset })` |
| 章のボスを倒し、報酬を選んで章クリアになったとき（トロフィーと同じ場所） | `rta.checkpoint(id, { igtMs: ターン数 })` |
| 敗北したとき・タイトルに戻ったとき | `rta.abort()` |

- RTA のモードでは、章選択で第 1 章しか始められない（第 2 章以降は押せない）
- 区切り ID：`tactics-ch1` は第 1 章クリアで `ch1`（そこで計測が終わる）。`tactics-all5` は第 1〜4 章クリアで `ch1`〜`ch4`、第 5 章クリアで `clear`
- **IGT はターン数**：その時点までの戦闘のターン数の合計（`runState.totalTurns`。SPEC-007 のランキングと同じ数え方）を `igtMs` の欄にそのまま入れる。共通基盤のレギュレーションの定義に `igt: 'turns'` があり、単位はそちらで分かる
- 計測が終わったら（第 1 章のレギュレーションで第 1 章をクリアしたあとも）、挑戦はそのまま続けてよい。計測はしない
- 計測中の経過時間（目安）は SDK が画面の上に出す。上端の資源の行に重ならないよう、`timerOffset` にその行の高さを渡す
- 区切り・中断は、計測中（`rta.current()` がある）のときだけ送る

### エラー条件

- SDK が読めない・通信に失敗した場合は何もしない（ゲームの進行を止めない・例外を出さない）。失敗は `console.warn` だけ

### 互換性

- 依存の追加はない。SDK は SPEC-008 で読み込み済み
- 端末への保存は増えない（レギュレーションを Common にするのは、ふつうの選択と同じ `mct.currentRegulation`）

## 6. 非機能要件

- 通信は、開始・区切り（最大 5 回）・中断と、SDK の「操作あり」（5 分に 1 回まで）だけ

## 7. Human-in-the-loop

- 最短時間は暫定。作者の通しプレイの記録を見て、共通基盤の `platform/rta.js` で直す（本作の変更は要らない）

## 8. 受け入れ基準

- [ ] レギュレーション選択画面に「RTA」の枠が出て、「RTA 第 1 章」「RTA 全 5 章」から Common で始まる
- [ ] 章選択で第 1 章を押すと、画面の上に RTA の経過時間が出る（資源の行に重ならない）
- [ ] 第 1 章のレギュレーション：第 1 章クリアで公式タイムの通知が出る
- [ ] 全 5 章のレギュレーション：章クリアごとに区間タイムの通知、全 5 章クリアで公式タイムの通知が出る
- [ ] 敗北・タイトルに戻ると計測が消える
- [ ] 記録が `https://bearko.games/rta/` のランキング（ログイン時）と `https://bearko.games/me/` に出る
- [ ] SDK が読めない状態では RTA の枠が出ず、ふつうのレギュレーションは今までどおり遊べる

## 9. テストと証跡

- `prototype/js/platform.js` の純関数（章 → 区切り ID）と、計測中だけ区切り・中断を送ること、SDK がない・失敗するときに例外を出さないことを Node 標準 `assert` でテストする（`tests/platform.test.mjs`）
- 手動 QA：上の受け入れ基準を PR 本文のチェックリストで確認する（ローカルでは共通基盤の `tools/e2e/` で通す）
