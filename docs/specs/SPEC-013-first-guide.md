## 1. 概要

初めての戦闘で、画面のどこを見て何をすればよいかを、**遊びを止めずに** 1 つずつ指し示す。マップはナビゲーターのマイがすでに案内しているので、戦闘だけを対象にする。

## 2. 背景と動機

- 今はヘルプ（?）しかなく、初めての人は最初の戦闘で「カードをどう使うか（タップで持ち上げ、もう一度で使う）」「敵の NEXT ACTION の意味」「いつターンを終えるか」で止まる
- 10 buy year・DeckBattle は、最初の数手だけ手順を絞って指し示す導入を持つ（bearko.games の UI/UX の共通の基準）
- DESIGN_CHARTER 1.6：敵の情報には `NEXT ACTION` のラベル。初見の人がそこを見るように案内する

## 3. 目標と非目標

### 目標

初回の戦闘だけ、対象を光る枠で囲み、その近くに短い吹き出しを出す。次の操作をしたら次の段に進む。

| 段 | 指す場所 | 文言（ja） | 次に進む条件 |
|---|---|---|---|
| 1 | 手札 | 「カードをタップすると持ち上がり、もう一度タップで使えます」 | カードを 1 枚使う（使わずにターンを終えたら段 2 へ） |
| 2 | エナジー | 「カードの左上の ⚡ がコスト。⚡ がなくなるまで使えます」 | もう 1 枚使う、または 6 秒 |
| 3 | 敵の NEXT ACTION | 「敵が次にすること。守るか攻めるかの手がかりに」 | 6 秒、または ターン終了 |
| 4 | ターン終了 | 「使い切ったらターン終了。敵が動きます」 | ターン終了を押す |

- 案内は `pointer-events: none`（下の画面をそのまま操作できる）。吹き出しの「×」だけ押せて、押すと案内を終える
- 見終えた（または × で閉じた）ら `localStorage["mct.guideSeen"] = "1"`。2 回目以降の戦闘では出ない（PROJECT_CHARTER 3.1 の「設定」に当たる UI の状態）
- ヘルプに「はじめての案内をもう一度見る」を足す（`mct.guideSeen` を消し、次の戦闘で出す）
- 文言は ja/en
- 演出を減らす / reduced-motion では、枠の点滅を止める（枠と吹き出しは出す）

### 非目標

- マップ・ショップ・クラフトの案内（マイの吹き出しがある）
- 操作の制限（案内中もどのカードでも使える）

## 5. 受け入れ基準

- [x] 初回の戦闘で段 1 が出て、カードを使うと段 2、時間か操作で段 3・4 と進み、ターン終了で消える
- [x] 案内中も手札・ターン終了を普通に操作できる
- [x] × で終わる。リロード後の戦闘では出ない
- [x] ヘルプの「もう一度見る」で、次の戦闘でまた出る
- [x] 390×844・1280×800 で、枠と吹き出しが対象からずれない・画面からはみ出さない
- [x] `node --test tests/*.test.mjs` が通る（`nextGuideStep` のテストを足す）
